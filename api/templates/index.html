How It Works

1. Input Images

Upload 2-4 lane images representing different traffic directions

2. Object Detection

YOLOv8 detects vehicles, emergency vehicles, and pedestrians

3. Priority Calculation

Each lane receives a score based on traffic conditions

4. Decision Making

The system determines which lane should get the green light

Scoring Algorithm:
  • Vehicles: 1 point per vehicle
  • Pedestrians: 0.5 points each
  • Emergency Vehicles: Highest priority (overrides normal scoring)
  • Jaywalkers: -0.25 points (slight penalty)
  • Starvation Control: Lanes waiting too long get bonus points
