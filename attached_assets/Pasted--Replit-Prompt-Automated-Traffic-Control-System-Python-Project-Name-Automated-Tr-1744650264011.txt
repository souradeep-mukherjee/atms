### **Replit Prompt: Automated Traffic Control System (Python)**  

**Project Name:** Automated Traffic Control System  
**Language:** Python  
**Key Technologies:**  
- **YOLOv8 (Ultralytics)** – Real-time object detection  
- **OpenCV** – Image processing & annotation  
- **NumPy** – Numerical operations  
- **Matplotlib (Optional)** – Debugging visualizations  

---  

### **How It Works**  

1. **Input:**  
   - Upload **2-4 lane images** (simulating different traffic directions).  

2. **Object Detection (YOLOv8):**  
   - Detects:  
     - **Vehicles** (cars, buses, trucks, bikes)  
     - **Emergency vehicles** (ambulance, fire truck, police)  
     - **Pedestrians** (crossing/jaywalking)  

3. **Priority Calculation:**  
   - **Vehicle Count:** 1 point per vehicle  
   - **Pedestrians:** 0.5 points each (unless jaywalking)  
   - **Emergency Vehicles:** Highest priority (overrides normal scoring)  
   - **Starvation Control:** Lanes waiting too long get bonus points  

4. **Decision & Visualization:**  
   - Selects lane with **highest priority score** for **green light**  
   - Displays:  
     - Original vs. annotated images (bounding boxes, counts)  
     - Traffic light status (red/green)  
     - Priority score breakdown  

5. **Cleanup:**  
   - Deletes temporary files for efficiency  

---  

### **Expected Output:**  
- **Annotated images** (vehicles, pedestrians marked)  
- **Priority scores** for each lane  
- **Selected lane** for green signal  
- **Warnings** (jaywalking, emergency vehicle detected)
